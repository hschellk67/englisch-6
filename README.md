# Englisch 6

Lern-App für Englisch in der 6. Klasse (Gymnasium Bayern): Vokabeln und Grammatik in einer App, mit Tagesplan, Lernkartei, Fehler-Liste und Probe-Schulaufgabe.

Live: https://hschellk67.github.io/englisch-6/
